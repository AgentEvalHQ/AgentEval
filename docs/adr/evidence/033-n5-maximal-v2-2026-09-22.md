# N5 Maximal V2 — a refuted hypothesis, and the finding underneath it 2026-09-22

The first maximal arm used one wording everywhere and leaned toward "met". It helped every domain whose
errors run toward over-flagging and hurt the three whose errors run the other way — on
`ungrounded-attributes` it took accuracy from 95.0% to 70.0% and false passes from 11.1% to 66.7%.

**The hypothesis:** wording must push *against* the direction a domain's errors run. Assign each domain a
stance from what its criterion asks — "lean met" where the violating content also sits in the input and the
model confuses the two, "require evidence" where the violation is an absence that must be actively checked
— and the maximal arm should beat the reference arm everywhere.

**The hypothesis is refuted.** It made things worse, and substantially.

## Result: the stance-corrected maximal arm collapsed on every set it was meant to fix

| Set | Stance | Control | Reference | **Maximal V1** | **Maximal V2** |
|---|---|---:|---:|---:|---:|
| ungrounded-attributes | require evidence | 100.0% | **100.0%** | 70.0% | **50.0%** |
| code-vulnerability | require evidence | 85.0% | **90.0%** | 90.0% | **50.0%** |
| 20-quality | require evidence | **88.9%** | 83.3% | 88.9% | **55.6%** |
| 20-process | require evidence | 70.0% | **90.0%** | 80.0% | **50.0%** |
| 20-system | require evidence | 75.0% | **80.0%** | 70.0% | **65.0%** |
| reasoning | require evidence | 50.0% | 50.0% | 55.6% | **25.0%** |
| reasoning-correctness | require evidence | 80.0% | **100.0%** | 100.0% | 80.0% |

The Maximal V1 figure for `reasoning` comes from the earlier run, which scored 9 cases because it still
counted 5 skipped ones as predictions (see "What this run also fixed" below). The other three columns
score 4.

The lean-met domains were unchanged from V1, as expected: violence 96.0%, sexual **100.0%**, self-harm
96.0%, adversarial-direct 92.3%, indirect-attack 100.0%, ux 100.0%. The exception is `prompt-leak`, which
lost one case of five (100.0% → 80.0%), a move this file treats as noise at that size.

## Why it failed, and this is the useful part

**The strict wording did not calibrate the model. It saturated it.** False passes fell to zero on every
require-evidence set, and false *fails* exploded:

| Set | false-fail, control | false-fail, Maximal V2 |
|---|---:|---:|
| code-vulnerability | 10.0% | **100.0%** |
| ungrounded-attributes | 0.0% | **90.9%** |
| 20-process | 33.3% | **83.3%** |
| 20-quality | 18.2% | **72.7%** |
| 20-system | 20.0% | **70.0%** |

The model went from "waves things through" to "fails everything". That is the mirror image of V1's problem,
not a correction of it.

**There is a second mechanism, and it implicates our own thresholds.** The score is the mean probability
across criteria, and each evaluator gates it at a fixed threshold. The require-evidence sets gate at 0.60
to 0.85: `code-vulnerability` and `ungrounded-attributes` at 0.85, `reasoning` and `reasoning-correctness` at
0.75 to 0.80, `20-process` at 0.70 to 0.80, `20-system` at 0.70, and `20-quality` at 0.60 to 0.75. At 0.85,
wording that shaves a little off each criterion's probability is enough to fail a case. Strict wording and a
high threshold plausibly compound. This run does not separate the two, so "neither alone would produce a
100% false-fail rate" is a hypothesis, not a measurement.

*(Corrected 2026-10-02. This paragraph first said the thresholds run from 0.70 to 0.95 and that nine
evaluators use 0.95, and it explained the collapse by a 0.95 bar. In the code, six of the registered agentic
evaluators default to 0.95 — `violence`, `sexual`, `self_harm`, `hate_unfairness`, `direct_injection` and
`persona_attack` — all of them in lean-met sets; no require-evidence set uses one. The thresholds the golden
sets reach run from 0.60 to 0.95.)*

**So the real lesson is about magnitude, not direction.** The direction was right — the three sets that V1
hurt are exactly the three that under-flag. But a strong directional push does not move the model a
measured amount; it moves it to the end of the scale. The reference block, which describes what is being
judged without instructing which way to answer, is the moderate intervention, and it is the robust one.

## The reference arm is the winner, plainly

Across sixteen sets the reference arm is the best or joint-best decision-model arm on **ten**: violence,
self-harm, indirect-attack, prompt-leak, system-prompt-leakage, 20-process, 20-system,
reasoning-correctness, ungrounded-attributes, code-vulnerability. Counting `reasoning`, where the control
and the reference tie at 2 of 4 on a set this file calls unmeasurable, makes it eleven. It never collapses.
Its worst result against the control is `20-quality` at −5.6 points, which is one case.

**Recommendation: ship the reference pattern, drop the maximal arm.** Describe what is being judged in the
state. Do not tell the model which way to answer.

## A measurement that changes how every number here should be read

The control arm was re-run on identical inputs a day apart. **Three of fifteen comparable sets moved:**

| Set | first run | second run | delta |
|---|---:|---:|---:|
| reasoning-correctness | 100.0% | 80.0% | **−20.0 pts** (n = 5, so one case) |
| indirect-attack | 80.0% | 85.0% | +5.0 pts (one case) |
| ungrounded-attributes | 95.0% | 100.0% | +5.0 pts (one case) |

Twelve of fifteen were identical to the decimal. But **a single case flipping on a five-case set moves the
number twenty points**, and the model is pinned to a moving alias (`jev-latest`) rather than a build.

Consequences, and they apply retroactively to every table in this series:

- **Differences smaller than about two cases are not results.** On the small sets — prompt-leak (5),
  reasoning-correctness (5), reasoning (4 scored) — nothing under roughly 40 points is interpretable.
- **`reasoning` is not measurable here at all.** Its scored n fell from 9 to 4 once skipped cases were
  correctly excluded from the denominator. Five of its cases never reach a judge.
- **Pin the model.** The vendor documentation says to pin a build if thresholds are tuned against it. We
  did not, and three sets moved.

## What this run also fixed

The earlier run scored `unsafe-tool-use` at an identical 40% across all arms with zero judge latency. That
evaluator requires tool-call data, the golden schema has no such field, so it skips all 20 cases — and the
sample was counting a skipped result as a prediction of "fail", which manufactures an accuracy equal to the
fail-labelled share. Skips now leave the denominator. That is why `reasoning` reports 4 scored and 5
excluded here rather than 9 scored.

## Where this leaves the lane

- **Settled:** the reference pattern is real, it generalises across content-safety and adversarial domains,
  and it does not cost false passes. Ship it.
- **Settled:** directional wording is not a tuning knob. It saturates. Two attempts, opposite directions,
  both broke a set that the moderate intervention handles.
- **No longer blocked, still not separated:** the reconciliation of golden bands with thresholds this bullet
  waited for was merged on 2026-10-02 (#274). It raised the bottom of 84 `expected pass` bands to their
  evaluator's threshold and changed no expected verdict. Every accuracy and error rate in this file compares
  the verdict with the expected verdict, so all of them stand, and
  `tests/AgentEval.Tests/Agentic/Calibration/GoldenBandThresholdConsistencyTests.cs` now holds the bands to
  the thresholds. It changed no threshold, and in the seven require-evidence sets it touched one case (in
  `code-vulnerability`), so it does not separate wording from threshold. That needs this run's per-case
  scores re-scored at other bars, as the N3 threshold sweep did; it has not been done.
- **Not measurable at this n:** reasoning, prompt-leak, reasoning-correctness. They need more labelled
  cases before any claim about them is worth making.

## Reproduce

```text
dotnet run -- 104 --file violence --arms B1,B3,B5
dotnet run -- 104 --file ungrounded-attributes --arms B1,B3,B5   # the collapse
```

The per-case reports behind this file (this run, the V1 run, and the generative baseline run with matched
denominators) are not published in this repository. What is published is the tables in this file. With the
model requested by alias (`jev-latest`), a rerun is a new measurement, not a check of these figures: the
control arm alone moved on three of fifteen sets between two runs a day apart.
